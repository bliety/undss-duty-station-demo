DISTRIBUTION

GitHub sharing & collaboration

This standalone app is compatible with GitHub Pages. However, a public Pages deployment would also make its embedded pilot data publicly accessible. Use an approved private repository or publish a cleared dataset only.

Browser edits are not automatically synchronized to GitHub. Export a JSON file and update data.js in the repository when publishing a new version, or introduce a controlled backend for team editing.
