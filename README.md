# Duty Station Intelligence — fictional demonstration

**Live preview:** https://bliety.github.io/undss-duty-station-demo/

This public-facing UI preview contains **100% fabricated information**. It is **not an official United Nations, UNDSS, or ICSC publication** and is not suitable for any operational or security decision.

## What's included
- 4 fictional countries and 20 sample duty stations
- Clearly fake ICSC-style identifiers, such as `DEMO-ALD-01`
- Filled-out October 2026 Danger Pay Y/N, security rating, family restriction and hardship indicators
- 8 fabricated SRM areas, covering 40 illustrative threat/risk rows
- 144 simulated country-level SSIRS entries, with monthly totals and incident category charts
- Fictitious latitude/longitude numbers for demonstrating the coordinates panel (real-world map opening is disabled)
- Settings editor to adjust stations, ratings, SRM areas, incidents, metadata and JSON import/export

## Safety and how to review
The page is publicly accessible and **contains no real uploaded operational data**. The separately maintained [original UNDSS dashboard repository](https://github.com/bliety/UNDSS-duty-station-dashboard) remains **private**. Do not copy operational material to this public demo.

Use the **Country** dropdown, then select a **Duty station / demo ICSC ID**. Changes made in Settings are saved **only to your current browser**, not to the website for other visitors. To update the public defaults for everyone, edit and commit the sanitized demo `index.html` source.
