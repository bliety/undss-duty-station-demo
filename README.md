# Happiness Atlas — storybook demonstration

Live: https://bliety.github.io/undss-duty-station-demo/

This is a **100% fictional** showcase. Countries, places, demo identifiers, grid positions, sunshine bonuses, comfort grades, retreat flags, event counts, and happiness levels are all invented. No real places or ICSC/UNDSS operational information appear in the public demo.

**Countries and places:**
- Sunoria: Sunhaven, Brightwater, Goldenmeadow, Solstice Bay, Peachgrove
- Moonvale: Moonbridge, Silverglade, Starling Point, Nightbloom, Lumenford
- Cloudria: Cloudrest, Skyharbor, Mistwood, Rainridge, Zephyr Falls
- Bloomara: Bloomfield, Roseport, Willowcross, Meadowgate, Lavender Hills

The Happiness Level section shows five invented aspects of life: community spirit, outdoor fun, friendliness, wellbeing, arts and culture. The map is a schematic SVG fantasy atlas and never requests real-world map tiles. The Settings and traceability panels remain hidden/removed in the public UI.

The **private real-data dashboard repository is not modified** by this public demo release.
