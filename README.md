# Public duty-station dashboard demo — real names, synthetic information

**Live site:** https://bliety.github.io/undss-duty-station-demo/

**Important:** This is an unofficial **demonstration of interface design only**, not a UN/UNDSS/ICSC dataset or official assessment.

The **country and duty station names are real** and are examples drawn from publicly listed ICSC duty stations. The **ICSC-style IDs are intentionally fake** (beginning `DEMO-`). All IDs and duty-station indicators are simulated: Danger Pay Yes/No, security ratings, hardship, family restrictions, SRM areas and threat levels, and SSIRS monthly incidents and totals. **Coordinates are approximate public city/town centre references, not UN premises or ICSC-approved duty-station locations.** **None of these simulated fields are current or historical real information.** Do not use this site for operations, entitlements, routing, or safety decisions.

## Included in the public preview
- South Sudan — Juba, Wau, Malakal, Bentiu, Bor
- Kenya — Nairobi, Mombasa, Kisumu, Kakuma, Dadaab
- Somalia — Mogadishu (Mogadiscio), Garowe, Hargeisa, Kismayo (Kisimaio), Galkacyo
- Germany — Berlin, Bonn, Hamburg, Dresden, Munich
- 20 populated fake ICSC-style IDs, 8 fabricated SRM areas, 40 threat entries, 144 fabricated SSIRS records, and simulated Y/N security and family flags
- The Settings interface is temporarily hidden in the public demonstration; its code remains available for a future release.
- Publicly sourced approximate geographic coordinates and an interactive OpenStreetMap city-centre map for each location. The map does not identify UN premises.

**Public name references:** [ICSC Mobility & Hardship](https://icsc.un.org/Home/DataMobility); [ICSC 2025 consolidated list](https://icsc.un.org/Home/GetDataFile/8596). These public references were used **only to choose the names of duty stations**, not to populate any status, risk, classification or numeric field.

The Data traceability section has been removed from the public overview. The original [UNDSS dashboard source](https://github.com/bliety/UNDSS-duty-station-dashboard) remains in a **private** repository. Never copy its data files into this public site.
